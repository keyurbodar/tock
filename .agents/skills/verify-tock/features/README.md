# Feature map

| Feature | Journeys | Proves |
| --- | --- | --- |
| [Sidebar](sidebar.md) | shell, resize | default 320px width, drag, keyboard and double-click resize that persists |
| [Thread actions](thread-actions.md) | menu, pin, rename, dialog, toasts | roster menu opens from the row's more button; pin, rename and delete-cancel round-trip through the server; Archive shows a toast whose Undo restores the row |
| [Chat](chat.md) | send, worklog | a new chat gets a UUID url that survives the first send; the activity line and work log are text only and open and close |
| Notification centre sheet | sheet, smooth | the centre slides from behind the rail on a live spring that retargets mid-flight (three quick bell clicks land it open); a short drag springs it back, a long drag or flick closes it; the chat recedes (scale, blur, dim) while it is open |
| [Shortcuts](shortcuts.md) | shortcuts, hotkeys, palette | `?` opens the shortcuts sheet; ⌘K opens the palette, filters, runs an action with Enter and closes on Escape |
| [Composer](composer.md) | plus, attach, mention, command | plus menu items, upload with progress, sent image and file card; `@` lists chats, inserts a thread token, first Backspace selects it and the second deletes it, the sent chip previews the chat after hover intent; `/` filters commands and runs one |
| [Links](links.md) | links | a typed URL plus a space becomes a link token; a sent link reads host and path behind the site's mark, gets no hover card, and right-click offers Open and Copy, which confirms with a toast |
| Sidebar motion | flip | archiving a row slides the rows below up into the gap (FLIP) and lands with no offset; Undo restores it |
| Connection | offline | the offline banner shows at once when the network drops (the socket is dropped without waiting for a close handshake) and turns to Back online on reconnect |
| [Interface rules](ui.md) | ui | hover gated to hover-capable pointers, unbreakable text stays in its bubble, truncated text keeps its full value reachable, controls at least 24×24, and at 320px home shows the list alone, a thread shows the chat alone with header and composer on screen, and Chats leads back |
| Motion rules | motion | no live element transitions `all`; buttons carry the press transition; an idle chat runs no infinite loops; under reduced motion transitions cap at 150ms and no element.animate() call moves anything (sending only fades) |
| Composer tray | trayfit | a large upload mid-chat: the progress ring never intersects the file name, and the grown composer never covers the last message in any painted frame (the column reserves the composer's live height) |
| Scroll edge fades | edges | at a short viewport the roster masks only its bottom edge at the top, both edges in the middle and only its top edge at the bottom, each fade the full `size.edge-fade` once scrolled past it; a roster that fits drops the mask; the /__motion strip fades only its right edge at the start |
| Tray motion | traygrow | a card grows out of the plus button, the composer height springs past rest and settles, a doc shows N% of size then morphs into its final meta, removal collapses through intermediate widths |
| Outbox | outbox | a send made offline waits in the IndexedDB outbox with the offline caption, flushes once on reconnect and gets a reply; a send left in the outbox survives a reload and flushes exactly once; the outbox drains |
| Error boundaries | faults | a throw in the transcript, composer or sidebar (dev-only `sessionStorage["tock.fault"]`) shows that surface's TDS error state with Try again while the others keep working, and Try again restores it |
| Long chats | longchat | a 500+ message chat (dev-only `__tockSeed` repeats real entries) mounts only its newest window under budget (render < 1000ms, < 4000 nodes), opens at the end, mounts older messages on scroll-up without losing the reader's place, and find mounts everything. Against a production build (`cd apps/web && VITE_TOCK_SEED=1 bunx vite build && bunx vite preview --port 4173`, then `TOCK_URL=http://localhost:4173 bun scripts/verify.ts longchat`) it scrolls all 650 bubbles from end to top at 60px per frame, fully mounted and again right after opening while older slices still mount, sampling after each paint, logs p50/p95/max and every frame over 50ms with its long-animation-frame attribution, and fails on any frame over 50ms where the page was busy (a task over 50ms, or over 16ms of script plus render). On the dev server it logs the numbers without gating |
| Prefetch | prefetch | hovering a row preloads its chat (router intentPreload), so clicking it paints its messages in the first frame with no skeleton or blank |
| Hover read | hoverread | hovering an unread row prefetches it without a chat.subscribe or thread.update frame, so it stays unread after a reload; opening it marks it read |
| Subscriptions | subscriptions | hovering rows sends no chat.subscribe (the socket streams only the open chat); a reconnect resubscribes the open chat alone; the IndexedDB transcript cache is keyed by chat id |
| Offline reload | offlinereload | (production build only: vite preview or a deploy; skipped on the dev server) the service worker caches the shell and its hashed assets and nothing under /api, /ws or /mcp; a reload while offline shows the app, the cached transcript and the offline banner |
| Half-open socket | halfopen | a malformed frame is dropped; a socket that stops answering is caught by the missed pong, the banner says Reconnecting… (the browser is online), it reconnects and the next send gets a reply |
| Inline code | codeexit | clearing toggled inline code drops the code mark, a backtick typed in code steps out without inserting, ArrowRight at the end exits |
| Composer round trip | roundtrip | every format typed with its input rule (heading, bold, italic, strike, code, quote, bullet, task, ordered, rule, [text](url) link, fence on Enter, closing fence exits), Shift+Enter leaves an empty quote or list item, typed `a_b_c` and `[ ]` arrive unescaped, and the sent bubble renders each format or shows its markdown source |
| Composer static shell | editorboot | with the editor chunk held back (dev-only `tock:hold-editor`), the composer renders a static shell with the same field box and placeholder; text typed there, focus and caret carry into the editor when it loads, and Enter pressed in the shell sends once it lands |
| Composer paste and keys | richpaste | heading and task markdown pastes land, a plain `file_name.py` paste stays text, an HTML table pastes as GFM, Mod-K in the editor wraps the selection as a link instead of opening the palette, Mod-E makes inline code (and does not archive), no underline, no Dictate button, the @ list groups this chat's Files above Chats and inserts a file token, the / list shows each description inline 8px after the command |
| Tray lightbox | trayopen | unsent tray cards are labelled buttons with a focus ring; Enter or Space opens the doc or image in the lightbox and focus returns to the card |
| Skeleton | skeleton | with the socket slowed (?slow, an init script) the sidebar rows, header title and transcript paint skullet bones from their own components; on a first visit the rows, column and composer sit where the loaded ones do, and on a reload of the chat (remembered shape) rows, bubbles, the activity line, the title pill and composer move under 1px when data lands |
| HEIC | heic | a HEIC photo shows Converting to JPEG, converts in the browser (heic-to, lazy chunk), previews as a picture and uploads as .jpg (needs ~/.capy/work/sample.heic) |
| PDF | pdf | a two-page PDF counts its pages on the tray card, the sent doc card shows page one as its thumbnail (pdf.js, on demand), and the lightbox draws every page with a page count in the bar |
| Health | diagnostics | no Solid diagnostics or page errors across the run |
- [media.md](media.md): image rows, doc cards, lightbox, finished-elsewhere dot (`lightbox`, `finished`)
- [ui.md](ui.md): interface/layout rules from the jk and ek skills (`ui`)
